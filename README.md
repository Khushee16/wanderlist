# Wanderlist — Find Your Next Trip

An interactive travel-destination explorer with a dozen hand-picked spots around the world. Search, filter, sort, and save favorites — everything runs client-side with instant feedback.

## Features

- Live search across names, countries, and descriptions
- Filter by region (Europe, Asia, Americas, Africa, Oceania)
- Sort by rating, price, or name; "favorites only" view
- Destination detail modal with photo, rating, trip length, and price estimate
- Favorites persisted in localStorage across visits
- Responsive card grid with hover lift/zoom, staggered entrance animations
- Empty state with one-click filter reset; keyboard accessible (Enter/Space/Escape)

## Tech

HTML, CSS (custom properties, grid), vanilla JavaScript. No frameworks, no build step — just open `index.html`. Photos via picsum.photos seeds.
